# GEO Live Audit

Real server-side AI-visibility audit. Enter any website URL — the tool fetches the site live (robots.txt, llms.txt, sitemap.xml, homepage HTML) and scores whether ChatGPT, Perplexity, Gemini and Google AI Overviews can find and cite it.

15 weighted checks across 4 categories: AI Crawler Access, Machine-Readable Facts, Answer-First Content, Trust & Tech. Every finding ships with the evidence it was based on.

Built with Next.js 15.
